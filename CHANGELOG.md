# Changelog

## v1.0.0 — Initial Public Release
- PC Quick Scan (NTFS `$MFT`, FAT32, exFAT, `$Recycle.Bin`) + Sector-by-sector Deep Scan.
- RAW / Lost Partition Scanner and `.img` Disk Imager with bad-sector skip.
- Save & Resume scan sessions (`.rpro`).
- Non-root Android Smart Deep Scan over USB or Wi-Fi ADB (trash, thumbnails, WhatsApp/Telegram media, `.vcf` contacts).
- Built-in previews (images, video/audio, PDF/Office/text, hex) and Photo Gallery Grid view.
- Multi-method file repair pipeline + auto-detected `Repairable / Not Repairable` column.
- 5 dynamic themes, 11 languages, and self-contained Windows x64 executable.
